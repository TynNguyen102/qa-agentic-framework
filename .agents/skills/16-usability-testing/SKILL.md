# Usability Testing

Base findings on user goals and observable criteria, not personal preference.
Read the UX/usability and end-to-end dimensions in `Config/QA-Agent/professional-coverage-model.yaml`; link tasks/findings to coverage units and business outcomes.

## Procedure

1. Define persona, context, prior knowledge, task, success criteria, and representative device.
2. Evaluate discoverability, navigation, terminology, cognitive load, feedback, consistency, efficiency, prevention of errors, and recovery from errors.
3. Record task completion, time or effort signals, hesitation, wrong turns, errors, and user comments where available.
4. Separate observation, usability finding, product defect, and enhancement suggestion.
5. Rate impact using task criticality, affected users, frequency, recoverability, and evidence.

## Output Contract

Return linked coverage unit, task, persona, observation, evidence, impact, frequency, severity, source criterion, recommendation, classification and residual usability risk.
