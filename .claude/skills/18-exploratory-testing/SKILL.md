# Exploratory Testing

Exploratory testing is simultaneous learning, test design, and execution. It must still be traceable.

## Procedure

1. Create a charter with mission, scope, risk hypothesis, persona or role, data, environment, timebox, heuristics, and exclusions.
2. Start from a known state and record significant actions, observations, paths, data, and timestamps while testing.
3. Vary state, sequence, role, data, interruption, dependency, boundary, and recovery behavior relevant to the charter.
4. Capture reproducible evidence for findings and distinguish observation, question, risk, and confirmed defect.
5. End with a debrief: coverage achieved, findings, new risks, blocked areas, and follow-up charters. Route confirmed defects to workflow 36.

## Output Contract

Return charter, session duration, build/environment, coverage notes, evidence, findings, questions, defects, and recommended next sessions.
