# Projects/

Thư mục này **để trống có chủ đích**.

Mỗi project thật là một thư mục con ở đây, tạo bằng cách copy
`Templates/Project-Scaffold/NEW-PROJECT-TEMPLATE/` sang `Projects/<tên-project>/`,
rồi khai báo trong `project/active-project.yaml`.

Khung dùng chung (skill, Config, governance, tools) **không** nằm trong đây và
**không** được sửa riêng cho một project. Xem `ADAPTING-TO-NEW-PROJECT.md`.
